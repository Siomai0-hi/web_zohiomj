ВЕБ ХУУДАСНЫ КОДЫН ТАЙЛБАР
Энгийнээр, алхам алхмаар

Эхлээд том зургаар нь ойлгоё
----------------------------
Вэб хуудсыг жижиг байшин гэж бодъё.

HTML бол байшингийн өрөө, хаалга, цонх хаана байхыг заасан зураг.
CSS бол ханын өнгө, тавилга, хэмжээ зэргийг сонгосон чимэглэл.
Зураг файл бол байшинд өлгөсөн зураг.
Хөтөч (Chrome зэрэг) бол энэ зургийг харагдах байшин болгодог хүн.

Энэ хавтсанд гурван гол HTML хуудас байна:
- Lab1.html: өөрийгөө танилцуулна.
- Lab2.html: чадвар, хобби, боловсролыг харуулна.
- Lab3.html: оюутны бүртгэлийн форм.

Мөн style.css нь Lab3.html-ийн өнгө, хэмжээ, байрлалыг тохируулна.
image.jpg нь Lab1.html дээр харагдах зураг юм.

1. Бүх HTML хуудсанд давтагддаг эхлэл
------------------------------------
<!doctype html>
Энэ мөр нь хөтөчид: "Энэ бол шинэ үеийн HTML хуудас" гэж хэлнэ.

<html lang="mn">
Хуудасны бүх код энэ элементийн дотор байна. lang="mn" гэдэг нь
хуудсын гол хэл Монгол гэж хөтөчид хэлж байгаа юм.

<head> ... </head>
Энэ бол хуудсын тухай мэдээллийн өрөө. Ихэнх нь шууд дэлгэц дээр харагддаггүй.

<meta charset="UTF-8">
Монгол үсэг болон бусад тэмдэгтийг зөв харуулна.

<meta name="viewport" content="width=device-width, initial-scale=1.0">
Хуудсыг утасны дэлгэцэд тааруулж харуулахад тусална.

<title>...</title>
Хөтчийн tab дээр харагдах нэр.

<link ...>
Өөр файлтай холбодог. Google Font болон CSS файлтай холбохдоо ашигласан.

<body> ... </body>
Хүн дэлгэц дээр харах бүх зүйл энд байна.

2. HTML-ийн үндсэн хэсгүүд
--------------------------
<header>
Хуудасны дээд хэсэг. Энд гарчиг болон цэс байдаг.

<nav>
Хуудас хооронд явах холбоосуудын цэс.

<ul> болон <li>
<ul> нь жагсаалт эхлүүлнэ. <li> нь жагсаалтын нэг мөр юм.
Цэсний холбоос бүр нэг <li> дотор байдаг.

<a href="Lab2.html">Дэлгэрэнгүй</a>
<a> нь холбоос. href нь холбоос дарахад хаашаа очихыг заана.
Жишээ нь Lab2.html гэвэл энэ хавтас дахь Lab2.html хуудсыг нээнэ.

<a href="tel:...">...
Утасны дугаар дээр дарахад дуудлага хийх үйлдэл эхлүүлнэ.

<a href="mailto:...">...
Имэйл хаяг дээр дарахад имэйл бичих програм нээнэ.

<main>
Хуудасны гол, хамгийн чухал агуулга.

<section>
Нэг сэдэвтэй зүйлсийг бүлэглэнэ. Жишээ нь "Холбоо барих" хэсэг.

<div>
Өөрөө онцгой утгагүй хайрцаг. Хэдэн элементийг нэг дор бүлэглэхэд хэрэглэнэ.

<h1>, <h2>, <h3>
Гарчгууд. h1 хамгийн гол, том гарчиг. h2 дэд гарчиг. h3 түүнээс жижиг.

<p>
Энгийн өгүүлбэр эсвэл догол мөр.

<strong>
Доторх үгийг илүү чухал, тод харагдуулна.

<footer>
Хуудасны доод хэсэг. Энд хичээлийн нэр зэрэг мэдээлэл байна.

id="..."
Нэг элементийг тусгайлан таних нэр. Нэг хуудсанд ижил id-г давтаж болохгүй.

class="..."
Ижил загвартай олон элементийг бүлэглэх нэр. CSS энэ нэрээр нь олж загвар өгнө.

aria-label, aria-labelledby, alt
Эдгээр нь дэлгэц уншигч зэрэг туслах хэрэгсэлд элементийн утгыг тайлбарлаж өгдөг.

3. Lab1.html: танилцуулгын хуудас
---------------------------------
<header> хэсэгт нэр, товч танилцуулга, үндсэн цэс бий.

<img src="image.jpg" ...>
Зураг харуулна. src нь зургийн файлын нэр. alt нь зураг харагдахгүй үед
эсвэл дэлгэц уншигч ашиглах үед зургийг үгээр тайлбарлана.
width, height нь зургийн анхны өргөн, өндрийг заана.

Хувийн мэдээллийн <ul> жагсаалтад ургийн овог, овог, нэр, төрсөн газрыг харуулна.

Холбоо барих хэсэгт хаяг, утас, имэйл, Facebook холбоос орсон.

"Дэлгэрэнгүй үзэх" холбоос Lab2.html хуудсанд аваачна.

4. Lab2.html: дэлгэрэнгүй хуудас
--------------------------------
Энэ хуудсанд чадвар, хобби, боловсрол гэсэн гурван бүлэг байна.

Авьяас, чадвар болон хоббиг <ul> жагсаалт, <p> өгүүлбэрээр бичсэн.

Боловсролын хэсэгт сургуулийн нэр, хугацаа, мэргэжил байна.

"Танилцуулга руу буцах" холбоос Lab1.html руу буцна.

5. Lab3.html: бүртгэлийн форм
-----------------------------
<form> бол мэдээлэл бичиж илгээдэг хэсэг.
action="#" method="post" гэдэг нь илгээх үйлдлийг заана. Гэхдээ энэ төсөлд
сервер байхгүй учир мэдээллийг хадгалж бүртгэх систем одоогоор холбогдоогүй.

<fieldset> нь холбоотой асуултуудыг нэг хүрээ дотор бүлэглэнэ.
<legend> нь тэр хүрээний нэр. Энд "Хувийн мэдээлэл" болон
"Боловсрол ба сонирхол" гэж бүлэглэсэн.

<label for="fullname">Овог нэр:</label>
<label> нь талбарын нэр. for-ийн утга input-ийн id-тай адил байх ёстой.
Тэгвэл label дээр дарахад тохирох талбар сонгогдоно.

<input type="text"> энгийн бичвэр авна.
<input type="email"> имэйл хаяг авна.
<input type="password"> бичсэн нууц үгийг цэг болгон нууна.
<input type="tel"> утасны дугаар авна.
<input type="date"> огноо сонгох боломж гаргана.

required гэдэг нь хоосон орхиж болохгүй гэсэн үг.
name нь формыг илгээх үед тухайн мэдээллийн түлхүүр нэр болдог.

Radio товч:
<input type="radio" ...>
Ижил name-тай radio-уудаас нэгийг л сонгоно. Энд эрэгтэй эсвэл эмэгтэйг
сонгох жишээ байна.

Checkbox товч:
<input type="checkbox" ...>
Checkbox-уудаас хэд хэдийг зэрэг сонгож болно. Энд сонирхож буй технологийг
сонгоно.

<select> болон <option>
Сонголтын жагсаалт үүсгэнэ. Жишээ нь бакалавр, магистр, докторант.

<textarea>
Олон мөрөөр бичих том талбар.

<button type="submit">Илгээх</button>
Формын мэдээллийг илгээх товч.

Lab3.html дээр одоогоор reset товч байхгүй. Хэрэв дараа нь
<button type="reset">Цэвэрлэх</button> гэж нэмбэл талбаруудыг хоосолж болно.

6. CSS гэж юу вэ?
-----------------
CSS нь HTML элементийн харагдах байдлыг шийддэг.

CSS-ийн энгийн дүрэм ингэж харагдана:

.form-label {
  display: block;
  margin-bottom: .25rem;
}

.form-label гэдэг нь class-ийн нэр.
{} дотор тухайн class-д өгөх загвар бичигдэнэ.
display: block гэдэг нь label-ийг өөрийн мөрөнд гаргана.
margin-bottom нь доод талд нь жаахан зай үлдээнэ.

style.css файл Lab3.html хуудсанд ингэж холбогдсон:
<link rel="stylesheet" href="style.css">
Ингэснээр өнгө, зай, хэмжээ зэргийг HTML-ээс тусдаа файлд бичиж болно.

7. style.css файлын тайлбар
---------------------------
:root {
  --text: #222;
  --line: #0adb3b;
  --blue: #0e16bd;
  --background: #f4f4f4;
}

:root дээрх --text, --line зэрэг нь өнгөө хадгалсан жижиг нэрс.
var(--blue) гэж бичвэл хадгалсан цэнхэр өнгийг ашиглана.

* { box-sizing: border-box; }
Од (*) нь бүх элементийг сонгоно. border-box нь өргөн, өндрийг тооцоход
padding болон border-ийг багтаадаг тул хэмжээ удирдахад амар болдог.

body {
  margin: 0;
  color: var(--text);
  background: var(--background);
  font-family: "Golos Text", Arial, sans-serif;
  line-height: 1.5;
}

Энэ хэсэг бүх хуудасны үсэг, үндсэн өнгө, дэвсгэр өнгө, мөр хоорондын зайг
тохируулна. margin: 0 нь хөтчийн автоматаар өгдөг гаднах зайг арилгана.
Golos Text бол Google Fonts-оос авдаг фонт. Ачаалахгүй бол Arial хэрэглэнэ.

.site-header, .main-layout, .content-panel
Цэгийн өмнөх нэр нь class selector. Жишээ нь .site-header нь
class="site-header" гэсэн HTML элементийг олно.

.site-header нь дээд гарчиг, цэсний зай болон арын өнгийг тохируулна.
.main-layout нь гол хэсгийн хамгийн их өргөн, гаднах зайг тохируулна.
.content-panel нь формыг цагаан дэвсгэртэй хайрцаг болгоно.

Box model буюу хайрцгийн загвар:
- content: дотор байгаа бичвэр, input зэрэг.
- padding: content ба хүрээний хоорондох дотоод зай.
- border: хайрцгийг хүрээлэх зураас.
- margin: хайрцгийн гаднах зай.

CSS-д padding, border, border-radius, margin ашигласнаар талбарууд
хоорондоо зайтай, цэгцтэй харагдана. border-radius нь буланг бага зэрэг
дугуйруулна.

.form-title-row { position: relative; }
Энэ нь гарчгийн мөрийг badge байрлуулах үндсэн хайрцаг болгоно.

.form-badge { position: absolute; top: ...; right: ...; }
Энэ жижиг тэмдэг нь үндсэн хайрцгийн баруун дээд хэсэгт очно.
relative нь badge-д "энэ хайрцгийг баримжаал" гэж хэлнэ.
absolute нь badge-г яг заасан top, right байрлалд тавина.

.form-row, .form-label, .form-control
Эдгээр нь формын нэг мөр, шошго, бичих талбаруудын зай, өргөн, хүрээг
тохируулна. width: 100% нь талбарыг боломжит өргөнийг дүүргэнэ.

.form-choice
Radio болон checkbox сонголтын үндсэн өнгийг тохируулна.

.form-button
Илгээх товчны зай, бичгийн өнгө, дэвсгэр өнгө, хүрээг тохируулна.

.site-footer
Хуудасны доод талын бичвэрийг байрлуулна.

@media (max-width: 520px)
Энэ бол жижиг дэлгэцийн дүрэм. Дэлгэц 520 pixel-ээс нарийн бол гарчиг,
формын гаднах зайг багасгаж, утсан дээр багтахад тусална.

8. Үсгийн фонтын холбоос
------------------------
HTML доторх Google Fonts холбоос Golos Text фонтыг татна.
Font link нь зөвхөн интернеттэй үед ажиллана. Интернетгүй байсан ч CSS дотор
Arial гэсэн нөөц фонт байгаа тул бичвэр харагдсаар байна.

9. Хуудаснууд хоорондоо яаж холбогдох вэ?
----------------------------------------
Lab1.html цэснээс Lab2.html болон Lab3.html руу орно.
Lab2.html-аас Lab1.html руу буцаж болно, мөн цэснээс Lab3.html руу орно.
Lab3.html-ийн "Нүүр" холбоос Lab1.html руу буцна.

Файлын нэрийг өөрчилбөл href доторх нэрийг бас өөрчлөх хэрэгтэй.
Жишээ нь файлыг Lab2.html гэж нэрлэсэн бол холбоос ч href="Lab2.html"
гэж яг ижил бичигдэнэ.

10. Одоогийн төслийн анхаарах зүйл
----------------------------------
Lab1.html болон Lab2.html дотор stylesheet-ийн нэр styles.css гэж байна.
Гэвч одоогийн ажлын хавтсанд style.css гэсэн нэг файл л байна.
Нэр нь яг ижил биш учраас эдгээр хоёр хуудсанд CSS холбогдохгүй байж болно.
Lab3.html нь style.css-тэй зөв холбогдсон.

Энгийн шалгах арга:
1. Lab1.html болон Lab2.html-ийн <link rel="stylesheet"> мөрийг хар.
2. href дотор байгаа нэрийг ажлын хавтас дахь CSS файлын нэртэй тулга.
3. Нэр зөрвөл зөв CSS файлын нэрээр солино.

Энэ төсөлд JavaScript файл байхгүй. Тиймээс формын мэдээлэл серверт
хадгалагдахгүй; энэ нь HTML формын харагдац, талбарын жишээ юм.

Хамгийн товч дүгнэлт
--------------------
HTML: юуг харуулах вэ гэдгийг хэлнэ.
CSS: тэр зүйлийг яаж харагдуулах вэ гэдгийг хэлнэ.
class: ижил загвар өгөх бүлгийн нэр.
id: нэг тодорхой элементийн нэр.
href: холбоос хаашаа очихыг заана.
src: зураг хаана байгааг заана.
margin: гаднах зай.
padding: доторх зай.
border: хүрээ.
position: relative/absolute: жижиг элементийг өөр элементийн дэргэд байрлуулах арга.

Ингээд л боллоо: HTML нь тоглоомын байшинг барьж, CSS нь өнгөөр будаж,
хөтөч нь бэлэн зүйлийг дэлгэц дээр харуулна.
